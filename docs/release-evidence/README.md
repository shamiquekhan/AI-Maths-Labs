- Central finite differences pass for polynomial, tanh, sigmoid, softplus
  (including `x=0`), division, softmax, BCE-with-logits at zero, MSE, broadcast
  add, matmul, and cross-entropy.
- Strict logistic analytical gradients match autograd to `5.55e-17`.
- Character GPT causal mask: earlier logits change by exactly `0.00e+00` when a
  future token is edited; the edited position changes by `2.77e+00`.
- GPT loss decreases `3.6104 → 3.1171` over 20 steps.
- Diffusion loss decreases `1.1676 → 0.9490` over 60 steps; sampler returns
  `steps + 1 = 13` frames for a 12-step schedule.

## Security notes

- `pip-audit -r requirements.txt` and the full environment report no known
  vulnerabilities. The development venv was upgraded from pip 25.2 to pip 26.3
  before the final audit.
- Bandit is run with `bandit.yaml`, which excludes:
  - `B311` — seeded `random.Random` is used for reproducible ML experiments,
    never for cryptographic material.
  - `B404`, `B603`, `B607` — fixed-argv `git` metadata calls in
    `core/experiment.py`, no shell and no user-controlled command.
- The secret scanner checks 199 files for private keys, cloud tokens, JWTs, and
  literal secret assignments, and fails if `.streamlit/secrets.toml` is tracked.
- Hybrid checkpoints use `torch.load(..., weights_only=True)`; strict
  checkpoints are JSON with a format marker and a size limit. No untrusted
  pickle loading.

## Honest limitations of this evidence

- The tests and examples run on one CPU machine and one OS; they are not a
  hardware matrix.
- The strict models are tiny and trained briefly. The numbers demonstrate
  correctness and learning, not benchmark quality.
- The public cloud deployment is prepared but not live; G9 remains partial until
  a URL is recorded in `deploy.md`.
- The Python 3.12 cloud-profile simulation runs locally, not on Streamlit's
  infrastructure. It proves the dependency set and entry point, not the hosting
  layer.
- The sdist and wheel are build artifacts only; no PyPI publication is claimed.
- The full environment includes CUDA-enabled PyTorch, but the deployment profile
  is torch-free. GPU results are not part of the deployment claim.
- Coverage omits `src/from_zero/app/*` by configuration; UI behavior is covered
  by AppTest instead.
